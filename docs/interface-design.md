# 上手流程与界面设计

本轮使用 [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill/tree/b9ca2fd/skills/taste-skill) 的应用界面流程。设计方案为 **Framed sheet**，seed `1092890362`，无重抽。保持 Flask / Jinja / 原生 CSS 和 JavaScript，不引入前端构建步骤。

## 真实对象与任务

- 对象是本机 Docker 容器，字段为名称、镜像、运行状态、实际 hosts。
- 需要更新的域名通常只有几个；首次安装为零，直接进入配置。
- IP 来自测速缓存或用户选择的固定地址，支持 IPv4、IPv6。
- 一个域名可能对应多个 IP，所有展示从实际 hosts 产物解析。
- 常用操作是立即更新，次常用操作是修改域名或目标容器。
- 运行结果包含逐容器成功、失败、尚未执行，不能用本地生成结果代替实际写入。
- 计划时间、最近成功和运行状态来自唯一任务服务。
- 历史最多 50 项，总览仅展示最近几项，其余在活动记录中查看。
- 操作者是自托管用户，初次设置一次，平时查看结果；手机同样需要完成配置。
- 不展示虚构的测速成绩、增长数据或装饰性图表。

## 每页回答的问题

| 页面 | 第一问题 | 最常用操作 |
| --- | --- | --- |
| 总览 | hosts 更新是否完成，哪里需要处理？ | 立即更新 |
| 更新规则 | 给哪些容器更新哪些域名？ | 保存并更新 |
| 容器 | 容器是否运行，实际 hosts 是什么？ | 查看 hosts |
| 活动记录 | 上次做了什么，失败原因是什么？ | 查看任务详情或日志 |

## 上手路径

首次进入配置页 → 从实际 Docker 列表勾选容器 → 填写域名 → 保存并更新 → 自动进入总览查看运行结果。

基础操作只需要选择目标和域名。自动更新默认沿用 12 小时；固定 IP、多 IP 数量、测速参数和超时放入高级选项。无法连接 Docker 时在选择器内解释原因并提供重试和手动输入；只生成 hosts 的用途作为明确的可选模式保留。

## 视觉与交互

白色工作面置于浅蓝灰框架中，无静态阴影。使用自托管的 IBM Plex Sans，中文采用系统中文字体；IBM Plex Mono 仅用于域名、IP、容器标识等技术数据。字体附带 OFL 许可证，不依赖外部 CDN。

产品标记以 hosts 的“映射连接”为形状。总览的“域名 → IP → 容器”更新链路使用实际配置与结果，作为本产品特有的主体；状态与更新时间紧邻操作。清晰区分运行状态、生成的映射和容器实际内容。

桌面保留带文字导航；平板和手机将导航折叠为菜单，所有核心操作可在触屏完成。保存采用统一提交模型，字段错误在对应字段旁显示。后台刷新保留输入、已打开的详情、滚动和键盘焦点。运行中只禁用会冲突的操作，并说明原因。

检查使用 taste-skill 的 lint 与 Chromium inspector，覆盖 1440、768、390px，随后进行实际操作与可访问性扫描。截图中的容器和域名使用隔离的测试数据，不会写入新安装的默认配置。

## 看图后的调整

1. 折叠手动输入、仅导出和高级测速选项，固定 IP 模式仅显示相关字段，缩短首次设置路径。
2. 手机端的更新链路改成纵向键值排列，IPv6 地址完整呈现，不在两列之间拆开。
3. hosts 预览约束在映射区宽度内；帮助图标补足可读名称，菜单与预览支持 Escape、点击外部关闭和键盘焦点返回。

数据核对：域名数量来自当前规则；目标数量来自当前选择；成功与失败来自任务逐目标结果；历史总数由数组长度计算；固定 IP 的 `0` 延迟不会被当作真实测速成绩展示。预览与测试使用 `tracker.pterclub.com`、`audiences.me`、`qingwapt.com` 和进程创建的 `cfhu-browser-…` 临时容器，不生成对外的性能或增长数据。

## 检查器提示的取舍

所有视图的 inspector 均无 FAIL。下列启发式 WARN 保留，并说明原因：

- `tiny-text`：12px 仅用于时间、镜像名、状态、操作辅助和次级说明，主标题、主数据与表单标签为 13–24px；自动扫描验证文字对比度。
- `hero-void` / `panel-void`：容器与活动页按两个真实目标和实际历史数量呈现，白色工作面保留全高框架，不虚构行或拉伸空卡填满屏幕。
- 源码 lint 的 `mono`：等宽字体仅用于实际容器标识、域名、IP 和 hosts 内容，符合应用界面的标识符规则。
- 源码 lint 的 `shadow`：阴影仅出现在浮动菜单、hosts 预览、提示和手机展开的导航上，静态面板没有阴影。
- 源码 lint 的 `em-dash`：破折号用于尚无数据的占位，不用于装饰性文案。

IBM Plex Sans / Mono 以本地 WOFF2 提供，合计约 64 KiB；中文使用系统字体。生产运行不请求字体 CDN，Node 与 Playwright 仅用于独立浏览器测试。
